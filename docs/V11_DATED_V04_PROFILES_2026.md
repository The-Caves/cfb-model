# V11 — Dated original V04 team components into the real-drive simulator

V11 is a **research-only** comparison with 2026 original weekly V04 predictions and true sequential possession simulation. It does **not** assume that all team scouting features were used by V04. A source audit confirms V04's actual fitted score uses: 2026 opponent rating from margins, separate fitted team offense and defense scoring, recency-weighted games (28d half-life for offense/defense), conservative neutral/home advantage and regularization. Advanced EPA and injury/weather fields are **not** included in V04's fitted-score regression despite their presence in separate current scouting views.

\`scripts/v11_dated_profile_bridge.py\` reconstructs V04's actual fitted neutral-team-strength, offense and defense scoring coefficients **at every original 2026 weekly cutoff**. It independently regenerates V04's predicted home and away points and refuses any game whose results differ from the paired V04 archive. It also reconstructs \`weekly_profiles.build_snapshots\` from the original prior 2026 games, which include past-only opponent-adjusted EPA, score form, win rate, run/pass and pressure profiles. All metadata includes earlier game IDs, weekly cutoff and source-quality flags; historical first-publication times are unverified.

\`scripts/v11_dated_profile_backtest.py\` runs the same game IDs, 2,000-trial seed, original V04 scores, fixed source-reconciled possession ledgers and real archived pregame sportsbook quotes for two possession variants. It requires **the whole current V04 week to be excluded** from both team's earlier drive history; the V10R2 baseline previously allowed earlier games on the same football week by target date, which is a less strict input window. The new paired variants use exactly the same cutoff, so changing the weekly opponent-adjusted EPA feature is isolated.

- V10 weekly-cutoff base: previously built possession hazard model, V04 scoring prior, turnover regression and raw historical advanced input.
- V11 dated-profile challenger: exactly the same hazard model and prior, but it **replaces** the raw EPA matchup input with the reconstructed earlier-week opponent-adjusted offense and opponent-defense EPA if BOTH teams have at least two verified games and the required adjusted metrics are known. It does not blindly add the two EPA signals together or apply arbitrary score bonuses.
- V04 deterministic original score: matched unchanged reference, not refitted or retroactively rescored in PRESSBOX.

The saved report has each team's original as-of dated V04 **neutral strength/offensive scoring/defensive scoring components**, plus dated advanced profile, matching source game IDs and complete feature-coverage flags. The new date profile layer does not override pregame starters, player injuries, weather, exact red-zone touchdown conversion, detailed clock/down-and-distance or unverified player status. SOS/SOR/SOV are available as separate as-of résumé research, not multiplied into scoring probabilities until incremental lift is proven.

**Caveat:** original 2026 PBP/source provider first-publication timestamps for earlier dates are still unauthenticated. This retrospective report cannot on its own prove genuine pregame betting performance. Do not promote candidates or overwrite past site picks. Evaluate same-cohort SU, margin/totals MAE, hypothetical ATS/OU where source prices exist, missingness, and week-by-week stability before considering any future shadow.
